# TRUCKLY — Data Dictionary

## Provenance tags

| Tag | Meaning |
|---|---|
| `OBS` | Observed / external real-world data |
| `BEN` | Published benchmark instance |
| `SIM` | Generated by the Truckly synthetic layer |
| `DRV` | Derived deterministically from other columns |
| `ASM` | Declared assumption, no external source obtained |
| `OPT` | Produced by the optimiser or the simulation |

> **The only `OBS` data in this project is the 40 node coordinates.** Everything describing freight is `SIM`, `DRV` or `ASM`. No row of this dataset is an observation of real Indian freight.
